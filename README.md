# Should Blake Do the Dishes Tonight?

Play it: https://mrpiercey.github.io/blake-dishes/

A rigged decision wheel. The CRT TV types out "Should Blake Do the Dishes Tonight?", you pull the lever, and the big YES / NO drum always lands on YES.

Made from the [Eagle Chase 5K wheel](https://github.com/mrpiercey/eaglechase-wheel). Open `index.html` in any browser; no build step. Deployed to GitHub Pages by `.github/workflows/pages.yml` on every push to `main`.
